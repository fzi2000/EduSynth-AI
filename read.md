# EduSynth AI  
### AI-Powered Study Notes Generator

EduSynth AI is a lightweight web app that turns any study text into **summaries**, **flashcards**, and **quiz questions** using AI.  
Perfect for students who want fast, organized revision material.

---

## ✨ Features

- **AI Summary** – Converts long text into simple bullet points  
- **AI Quiz Generator** – Creates MCQs or revision questions  
- **AI Flashcards** – Generates term–definition pairs  
- **Modern UI** – Gradient background, polished layout  
- **Fast & Simple** – Flask backend with no database required  

---

## 🛠 Tech Stack

- **Frontend:** HTML, CSS  
- **Backend:** Python Flask  
- **AI Engine:** OpenAI API  
- **Deployment:** Render
